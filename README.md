## ✨ Features

- **Hero Section**: Dynamic introduction featuring an interactive 3D icon cloud.
- **About Me**: A detailed breakdown of my personal background and career overview.
- **Skills Section**: Categorized display of technical skills and tools.
- **Projects Showcase**: Highlighted projects complete with GitHub repository links and live demos.
- **Certifications**: Timeline or grid-based display of verified achievements.
- **Contact Section**: Simple, accessible, and functional contact options.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices.
- **Dark / Light Mode**: Seamless theme switching for better accessibility and user preference.

## 🛠️ Getting Started

Follow the steps below to set up and run the project locally on your machine.

### Prerequisites

Ensure you have the following installed:
* **Node.js** (Version 18 or higher recommended)
* **npm** (Comes bundled with Node.js)

### Installation

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/bdharshan22/My-Portfolio.git](https://github.com/bdharshan22/My-Portfolio.git)
    cd My-Portfolio
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

    The application will be available at `http://localhost:5173`.
