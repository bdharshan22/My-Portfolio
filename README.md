🌐 My Portfolio

A modern, responsive personal portfolio website built with React, Vite, and Tailwind CSS.
This project highlights my skills, projects, certifications, and provides a clean and simple way to connect with me.

🛠️ Getting Started

Follow the steps below to set up and run the project locally.

Prerequisites

Node.js
 (Version 18 or higher recommended)

npm
 (comes bundled with Node.js)

Installation

Clone the repository

git clone https://github.com/bdharshan22/My-Portfolio.git
cd My-Portfolio


Install dependencies

npm install


Start the development server

npm run dev


The application will be available at:

http://localhost:5173

📦 Building for Production

Create a production-ready build using:

npm run build


The optimized output will be generated in the dist folder.

To preview the production build locally:

npm run preview

🚀 Deployment

This project is deployed using Vercel, which provides seamless integration with Vite and GitHub.

Deployment Steps

Push the project to a GitHub repository

Log in to Vercel and click Import Project

Select the repository

Vercel automatically detects Vite settings

Click Deploy
